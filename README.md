The world's news in one image — Thursday 19 November 2026: 36 stories,
6 continents, one front page. Trump, Xi and Putin meet in Shenzhen; the Gulf
war widens to Kuwait and Bahrain; GTA VI opens Vice City at last. Every story
happened or was first reported on 19 November 2026, with a DATE CHECK box
naming the 17-18 November stories deliberately left out.

A program that writes the day's world news as one 1024x1024 image.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes the image to `out/entry.png`. In the grader, `python3 main.py`
writes it to `/output/entry.png`.
